# Nesibe Kırış Can

Personal website for Nesibe Kırış Can, AI Governance Advisor, Keynote Speaker and Researcher.

English: `index.html`. Turkish: `tr/index.html`.

## Preview locally

Run `python3 -m http.server 8080` from the repository root and open http://localhost:8080.

## Hosting

This is a buildless static website. Serve the repository root on a static host. Asset links start at `/`, so use a root domain or root-level GitHub Pages site.

The contact form prepares an email draft; it does not submit information to a server. TechLetter subscriptions are completed on Substack. The newsletter invitation remembers dismissal locally for 30 days and can be reopened from the footer.
